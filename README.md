# ECG Privacy Risk Experiment

This repository contains the experimental pipeline for analyzing
privacy risks in ECG data, focusing on:

- Re-identification
- Linkability
- Feature-level privacy risk

The project is structured as a reproducible research pipeline using
Jupyter notebooks.

## Structure

data/
    raw/
    interim/
    processed/

notebooks/
    preprocessing
    segmentation
    feature_engineering
    modeling

outputs/
    figures
    tables
    models
