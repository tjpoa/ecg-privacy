# JBHI ECG article - Overleaf package

This folder is self-contained for import into Overleaf.

## Files

- main.tex: manuscript source.
- references.bib: article-only bibliography containing the 31 cited entries,
  ordered by first appearance in the manuscript.
- IEEEtran.cls: IEEE journal document class.
- IEEEtran.bst: IEEE bibliography style.
- figures/: figures referenced by main.tex.

## Overleaf import

Upload the contents of this folder as a new Overleaf project, or compress the
folder and use Overleaf's Upload Project option. Set main.tex as the main
document if Overleaf does not select it automatically.

Before submission:

1. Confirm author names, order, affiliations, and corresponding-author details.
2. Check the data/code availability, funding, ethics, and conflict-of-interest
   statements.
3. Keep the privacy claim bounded to the tested same-retained-record linkage,
   attribute-inference, and waveform-decoder protocols; the manuscript does
   not claim cross-session patient re-identification resistance, universal
   reconstruction resistance, or end-to-end differential privacy.
4. Compile and inspect the page layout, tables, figures, citations, and
   bibliography.
5. Confirm that all numerical values still match the canonical result table in
   the thesis project.

The default build is the eight-page submission version. Extended configuration,
dimension-sensitivity, EER, attribute, and per-lead reconstruction tables remain
preserved in `main.tex` behind the disabled `includeappendices` switch and are
not part of the submission PDF.

The new attack-extension values are generated by
`src/run_attribute_inference_attack.py`, `src/run_reconstruction_attack.py`,
`src/run_conditioned_reconstruction_attack.py`, and
`src/summarize_attack_extensions.py` using the final 40,000-segment,
25-iteration encoder protocol. The conditioned reconstruction run trains its
grouped decoder on oracle same-record means and tests oracle, link-selected,
and random aggregates against the anchor waveform.

The exploratory normalization sensitivity pilot used during revision is
available in `../outputs/tables/normalization_sensitivity_pilot/` and is not a
replacement for a full-dataset normalization ablation.
