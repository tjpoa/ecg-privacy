# JBHI submission declarations checklist

The manuscript now contains conservative ethics and data/code-availability
wording. Before submission, complete and verify the following items:

- Funding: state the funding agency and grant number, or confirm that there was no specific funding.
- Conflicts of interest: confirm the exact statement for all authors.
- Code repository: add the permanent public URL, DOI, or repository identifier.
- Dataset ethics: the PhysioNet documentation reports IRB approval by Shaoxing People's Hospital and Ningbo First Hospital, waived informed consent, and public sharing after de-identification; verify that this wording matches the submission requirements.
- Dataset license: the PhysioNet page identifies the files as Creative Commons Attribution 4.0 International; retain the citation and confirm that the intended derived-code release is compatible.
- Acknowledgment: add institutional, technical, or dataset acknowledgments if applicable.
- Author contributions: prepare the contribution statement if requested by the submission system.
